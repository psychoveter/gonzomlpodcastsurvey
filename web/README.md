# gonzomlpodcastsurvey — architectures SPA

Interactive D3 circle-packing map of architectures and techniques discussed in
the [@gonzo_ML_podcasts](https://t.me/gonzo_ML_podcasts) Telegram channel.

The data (`public/data.json`) is produced by the upstream Python pipeline in
the `gonzo` project (scrape → stitch → enrich → classify → LLM classify →
hierarchical clustering → `build_web_data`). This repo only ships the SPA and a
prebuilt snapshot of `data.json`.

## Run locally

```bash
npm install
npm run dev
# http://localhost:5174
```

## Build

```bash
npm run build       # static bundle in dist/
npm run preview     # local preview of the build
```

The build's `base` defaults to `/gonzomlpodcastsurvey/` (matching the GitHub
Pages URL `https://<owner>.github.io/gonzomlpodcastsurvey/`). Override with
`VITE_BASE` for custom hosting:

```bash
VITE_BASE=/ npm run build              # served from the root of a domain
VITE_BASE=/custom/path/ npm run build  # any sub-path
```

## Deploy to GitHub Pages

The workflow at the **repo root** (`../.github/workflows/deploy.yml`, since
this SPA lives at `web/` inside the larger `gonzo` repo) builds on every push
to `main` that touches `web/**` and publishes `web/dist/` via the official
Pages actions. `defaults.run.working-directory: web` keeps `npm ci` /
`npm run build` scoped to this directory.

One-time setup on the repo:

1. **Settings → Pages → Build and deployment → Source:** select **GitHub
   Actions**.
2. Push to `main` (or run the workflow manually via the *Actions* tab).
3. The workflow logs surface the live URL,
   `https://<owner>.github.io/gonzomlpodcastsurvey/`.

If the repo name differs from `gonzomlpodcastsurvey`, change `VITE_BASE` in
the workflow (and optionally in `vite.config.js` for `npm run build` without
the env var) to `/<repo-name>/`.

## Refreshing the data

`public/data.json` is regenerated by the upstream pipeline:

```bash
# from the parent gonzo/ project
PYTHONPATH=src python -m gonzo.build_web_data \
  --db data/gonzo.db --hierarchy reports/hierarchy.json \
  --out web/public/data.json
```

Commit the new `public/data.json` and push — the next CI run will redeploy.

## Layout

- `src/App.jsx` — top-level layout, search, legend, jump-to wiring.
- `src/CirclePack.jsx` — D3 circle-pack rendering with wheel-zoom, drag-pan,
  collision-resolved labels and per-paper title wrap.
- `src/DetailPanel.jsx` — right-hand side panel (family/cluster/paper info).
- `public/data.json` — prebuilt hierarchy + paper metadata.
- `index.html`, `vite.config.js`, `tailwind.config.js`, `postcss.config.js` —
  build configuration.
- `.github/workflows/deploy.yml` — GitHub Pages workflow.

## Controls

- **scroll wheel / two-finger scroll** — zoom in/out around the cursor.
- **click + drag** — pan the view.
- **click bubble** — drill into a family / cluster and open its description in
  the side panel.
- **click background** — reset to the full map.
- **search** — highlights matching titles / concepts and dims the rest.
